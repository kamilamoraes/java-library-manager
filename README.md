# Java Library Manager

A simple library management system developed in Java to practice object-oriented programming, programming fundamentals, and problem-solving skills.

## Features

- List available books
- Register new books
- Search for books by title
- Validate book titles and publication years
- Validate menu options
- Limit the library capacity to 10 books
- Display messages for successful operations and invalid inputs

## Project Structure

- `Main.java`: Handles the menu and user interaction.
- `Livro.java`: Represents a book, storing its title, author, publication year, and ID.
- `Biblioteca.java`: Manages book listing, registration, searching, and validation.

## How to Run

1. Make sure the Java Development Kit (JDK) is installed.
2. Clone or download this repository.
3. Open the project in your preferred Java IDE or terminal.
4. Compile the Java files:

   ```bash
   javac Main.java Livro.java Biblioteca.java
   ```

5. Run the program:

   ```bash
   java Main
   ```
